⚡ StreamPay

Continuous, per-second payment streams for Stellar — payroll, DAO contributor pay, subscriptions and vesting. Sablier-style money flow, native to Soroban: funds accrue linearly between start_time and end_time, the recipient withdraws at any time, and cancellation refunds the unaccrued remainder pro-rata.

 available  = streamed − withdrawn            ; 0 before start

Spec edge cases — all covered by tests

  • Withdraw before start_time → available = 0
  • Withdraw at / after end_time → full remainder
  • Cancel fully-withdrawn stream → reverts, not double-pay
  • Cancel before start → 100% refund to sender
  • Top-up after end → funds fully accrued, withdrawable
  • Sequential partial withdrawals → monotonic, never over
  • Checked math → i128::MAX deposits, 100-year windows
  • Zero duration / zero amount → rejected at creation
  • Reentrancy → CEI ordering, malicious-token test
  • Property test → partial sums ≤ full-window accrual
  • Pause / resume → accrual frozen, resumes exactly where it left off
  • Paused window → end stretches by the paused interval
  • While paused → withdraw, top up and cancel all still work
